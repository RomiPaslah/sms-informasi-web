## 🔄 Workflow Development & Deployment

### 🛠️ Development (Local)

```
1. Edit file di folder app/src/
   app/
   └── src/
       ├── pages/     (halaman baru)
       ├── components/ (komponon baru)
       ├── context/    (state management)
       └── lib/        (utilities)

2. Run dev server
   npm run dev
   → http://localhost:5176/

3. Test perubahan di browser
   (live reload otomatis)
```

### 🚀 Build & Deployment

```
1. Build untuk production
   npm run build
   → Output: app/dist/ & auto-copy ke public_html/

2. Verify build lokal
   npm run preview
   → Test production build

3. Upload ke cPanel
   Copy semua files dari public_html/ → cPanel public_html

4. Verify di production
   Buka https://yourdomain.com
   → Check halaman & features
```

## 💾 Backup & Restore

### Backup Data (dari Browser)

```
1. Buka website
2. F12 → Application → Local Storage
3. Copy seluruh data (JSON format)
4. Save ke file .json sebagai backup
```

### Restore Data

```
1. Buka website
2. F12 → Application → Local Storage
3. Clear semua
4. Paste backup data
5. Refresh page
```

## ⚙️ Konfigurasi Penting

### Build Configuration (`vite.config.ts`)

```typescript
export default defineConfig({
  base: './',  // ← Relative paths (penting untuk cPanel)
  plugins: [react()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

### Apache Routing (`.htaccess`)

```apache
Options -MultiViews
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^ index.html [QSA,L]
```

↑ Must be in `public_html/` root

### TypeScript Configuration (`tsconfig.json`)

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "paths": {
      "@/*": ["./src/*"]  // ← Path alias untuk imports
    }
  }
}
```

## 📞 FAQ

**Q: Dimana saya edit homepage?**
A: Admin Dashboard → "Edit Halaman Depan" tab

**Q: Gimana cara ganti logo?**
A: Taro gambar baru ke `app/public/images/`, edit `src/components/Navbar.tsx`

**Q: Data saya kemana kalau clear browser cache?**
A: Hilang (simpan backup). Untuk permanent data, butuh database backend.

**Q: Bagaimana update website setelah deploy?**
A: Edit `app/src/` → `npm run build` → upload `dist/*` lagi

**Q: Kenapa ada 2 folder (app & public_html)?**
A: `app` = development (source code), `public_html` = production (yang di-host)
