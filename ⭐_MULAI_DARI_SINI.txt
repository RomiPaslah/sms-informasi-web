LANGKAH 1: Buka cPanel
────────────────────

2. Klik "File Manager"

LANGKAH 2: Hapus File Lama (Optional)
──────────────────────────────
1. Select semua file di public_html (jika ada)
2. Delete (atau backup dulu jika perlu)

LANGKAH 3: Upload File Baru
──────────────────────────────
CARA 1: Drag & Drop (PALING MUDAH)
─────────────────────────────────
1. Buka Windows Explorer
2. Navigate ke: C:\Users\SPC STYLE 5\Downloads\SMS Informasi Web\public_html\

1. Klik tombol "Upload" di File Manager

─────────────────────────────────────────
1. Di cPanel File Manager: Settings ⚙️
2. Centang "Show Hidden Files"
3. Upload file .htaccess

LANGKAH 4: Verifikasi
───────────────────────
Setelah upload selesai:

1. ✅ Buka browser: https://yourdomain.com
   → Harus muncul halaman beranda (BUKAN blank putih)

2. ✅ Test navigasi
   - Klik "Berita" → halaman berita muncul
   - Klik "Tentang" → scroll section about
   - Klik "Admin" → login page muncul

3. ✅ Buka F12 Console
   - Tidak boleh ada error MERAH
   - Warning tentang Tailwind OK

4. ✅ Cek Network Tab
   - assets/index-*.js: status 200 atau 304
   - assets/index-*.css: status 200 atau 304
   - images/*.jpg: status 200 atau 304

Jika semua ✅ → SELESAI! Website berjalan!

🔍 TROUBLESHOOTING JIKA ADA MASALAH
═══════════════════════════════════════════════════════════

MASALAH 1: Halaman Blank/Putih
────────────────────────────────
Solusi:
1. Buka F12 Console
2. Cari error message dengan format [ErrorBoundary] atau [main.tsx]
3. Baca error message dengan teliti
4. Kemungkinan penyebab:
   - .htaccess tidak ter-upload → upload .htaccess
   - Assets tidak load → verify assets/ folder ada
   - JS error → reload page (hard refresh: Ctrl+Shift+R)

MASALAH 2: 404 saat buka /berita, /admin, halaman lain
───────────────────────────────────────────────────────
Penyebab: .htaccess tidak aktif atau tidak ada
Solusi:
1. Check .htaccess ada di cPanel public_html
2. Jika tidak ada → upload .htaccess
3. Cek permission: setter ke 644
4. Jika masih 404:
   - Contact hosting support
   - Ask mereka enable mod_rewrite di Apache

MASALAH 3: CSS/Images tidak muncul
────────────────────────────────────
Penyebab: Assets tidak ter-upload dengan benar
Solusi:
1. F12 → Network tab
2. Cari file yang status BUKAN 200
3. Verify file ada di server via File Manager
4. Check path spelling (case-sensitive!)

MASALAH 4: Login tidak work
───────────────────────────
Penyebab: Browser cache atau localStorage corrupt
Solusi:
1. Hard refresh: Ctrl+Shift+R
2. Atau clear browser cache completely
3. Try login again
