🆘 TROUBLESHOOTING JIKA ADA MASALAH
════════════════════════════════════════════════════════════════════

PROBLEM: Halaman Blank/Putih Saat Buka
───────────────────────────────────
Kemungkinan:
1. React JS tidak load
2. Error di component
3. localStorage access error
4. CSS tidak load

Solusi:
1. F12 Console → cari error
2. Hard refresh: Ctrl+Shift+R
3. Clear cache & cookies
4. Check assets tersedia di server


PROBLEM: 404 pada halaman /berita, /admin, dll
────────────────────────────────────
Penyebab: .htaccess tidak aktif/tidak ada

Solusi:
1. Verify .htaccess ada di public_html/
2. Check permission: 644
3. Contact hosting support:
   - Ask: "Enable mod_rewrite di Apache"
   - Tell: "We use SPA routing with .htaccess"


PROBLEM: CSS/Images tidak muncul
────────────────────────────────
Penyebab: Path salah atau file tidak uploaded

Solusi:
1. F12 Network tab → cari 404
2. Check file ada di File Manager
3. Verify folder structure:
   - public_html/assets/
   - public_html/images/


PROBLEM: Cannot write .htaccess
───────────────────────────────
Penyebab: Permission issue atau .htaccess corrupt

Solusi:
1. Delete existing .htaccess
2. Create new via File Manager:
   - Create File → nama ".htaccess"
   - Edit content → copy dari documentation
   - Save & set permission 644

📞 FAQ
════════════════════════════════════════════════════════════════════

Q: Kenapa masih warning saat build?
A: Warning Tailwind adalah normal. Bukan error. Ignore saja.

Q: Apakah data aman?
A: Data disimpan di browser localStorage. Jika clear cache → hilang.
   Untuk persistent data → butuh database backend.

Q: Bisa update tanpa upload ulang?
A: Konten via admin OK. Code/design → harus rebuild & upload.

Q: Hosting tidak support .htaccess?
A: Gunakan HashRouter untuk # routing. Rebuild & upload.

Q: Google OAuth tidak berfungsi?
A: Pastikan VITE_GOOGLE_CLIENT_ID sudah diisi di .env file di server.
   Domain harus HTTPS. Authorized origins di Google Console harus match.

Q: Error "Cannot find module"?
A: Pastikan .htaccess ter-upload & aktif. Jika tidak support → rebuild dengan HashRouter.

Q: Lambat loading?
A: Normal di koneksi lambat. Enable gzip di cPanel. Optimize images jika perlu.

Q: Bisa pakai domain berbeda?
A: Ya, tapi configure Vite base path jika di subfolder.
